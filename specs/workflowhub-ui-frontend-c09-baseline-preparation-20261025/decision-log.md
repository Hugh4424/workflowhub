#### D-004 — 无稿用 PaperBuilder 真实服务，做“费用配置改回”的可回滚闭环

- **做什么**：先过可行性门禁（服务可达、目标卡可读、费用配置可读），然后对**一张明确指定的已有模拟卡**跑闭环：列卡 → 读卡详情 → 读费用配置列表与当前值 → 选中另一个费用配置 → 读回确认 → **改回原配置** → 再读回确认恢复。记录前后值与卡片更新时间变化。依据批次 03、批次 05（质询三与改选）、D9 回传与 PRD 第 376 行。
- **不做什么**：不建后端、不造 mock、不改 PaperBuilder 代码、不批量操作、不动其它业务对象；不新增卡片、不走复制/丢弃/归档这类会新增对象或改变状态语义的写操作；不把 HTTP 200 或页面提示当业务结果；门禁不过时不得把只读或其它写操作当已交付。
- **风险**：**用户已接受**——写会落到 19G 真实库，卡片更新时间和费用来源字段会变，库还被在线服务持锁可能偶发失败。缓解：只操作一张指定卡、前后各读回一次、痕迹逐条登记、不做硬删；冲突保留原始错误不重试放大。门禁或改回失败时记“无可回滚写操作”或“未能恢复”，判准备不完整，不换别的写操作冒充。
