## 整体形态

目标是让用户用更少的时间和主 Agent token 得到可靠交付。入口先说明任务适合哪个级别、为什么推荐；用户选定后，Agent 先从原始需求整理可读骨架，再按模块调研、发散、讨论和收敛，最后把整件事讲清楚。小任务缩短路线，复杂任务保留必要的计划、实施和独立验证，规划任务交 PRD。四级都保留“大纲→收敛”，不限制提问数量。

实施者只读自身任务所需的决定、共享定义和 Phase。四类材料各服务明确读者；同一事实只留一个正文位置，其余引用。材料必留小节与按需小节分开，保留稳定的节名、语义和顺序，不再把所有候选节机械填满。拆分依据沿用已交付的“可独立交付验收单元”，不重新造拆分平台。

主会话负责用户选择与整体汇总，研究和实施重活进入独立子代理上下文。派发和回传用同一套必要字段，缺失如实可见；并发值只有一处权威。技能清单、正文和人读索引各有一个读者，保持现有常驻策略，按需要读技能，不修改宿主全局技能目录。

执行过程中，原始需求到提交 PR 的十个环节留下可读事实。缺失、跳步、测试失败和 provider 不可用会被报告；这些事实不新增推进门。新增检查只接现有报告通道，并用真实负例证明能发现问题。审查频率按改动范围、影响范围、改动大小决定；终末审查与独立性保留，不能用减少审查次数冒充质量提高。

收口由主会话执行既有收口技能，handoff 是其中一部分；领域知识、worktree/task、handoff、close 和 PR 各有一处权威说明。在已授权业务仓根产生并追加 `Improvements.md`，没有发现时写清依据；越界或能力缺失如实说明。外部技能的采用内容、固定来源与本地差异可查，人工可检查上游是否前进，自动同步不在本次承诺内。

改造是否有效，最后由同条件的真实阶段对比回答。复用 ModelTest US-07 固定上游 cohort，审查九面基准作辅助；主 Agent 成本单独采集。已经有的单样本观测继续用，不重建；缺少的跨样本稳定性、前后对比和质量信息必须补齐。现在不能承诺下降百分比。

### 四级路线的用户结果

这是待实施目标；当前规划不会修改运行时路由。级别独立于现有 `TASK_TYPES`，不扩其受控值集合。

| 级别 | 用户实际得到什么 | 路线与审查差异 |
| --- | --- | --- |
| 小改动 | 明确目标、简短决定与极简 spec，随后改动和目标测试 | `make-decision` → `build-code` 轻档；不调用 build-plan、build-prd、verify-code；无独立审查 |
| 普通任务 | 内部调研和 `talk-with-zhipeng` 明确方案，再实现、测试和审查 | `make-decision` 含一次方案审查 → `build-code` 轻档含一次实现审查；跳过 build-plan、build-prd、verify-code |
| 复杂任务 | 完整方向、实现计划、按 Phase 实施和终末验证 | 沿标准开发路线 make-decision → build-plan → build-code → verify-code；需要规划任务组时使用既有 build-prd，不强迫空跑全部入口 |
| 规划任务 | 已确认方向与完整任务组 PRD | make-decision → build-prd；不进入 build-plan、build-code、verify-code |

小改动与普通任务用 `build-code` 轻档承载“实施与测试”，是 D-003 留下的记录者设计判断，用户可覆盖；本稿不把它改写为用户逐字决定。T7 负责验证能否真正跳过非必要阶段，空跑不算跳过。拿不准时给出较重推荐，升级只补未做步骤，降级须有用户选择。

保留现有五种入口与公共 runtime 七类工具；不新增 stage、阻断门、第二进度权威、双写、永久兼容桥或历史运行分支。不会重做上游已交付部分，不改归档任务、旧报告和旧失败原件。已授权的两轮基线修复是既有事实；本次 PRD 调用不延长其代码或 Git 授权。

## 共享定义与责任边界

- **已交付**指当前决定和原件已记录的真实交付；本地图承诺不等于代码、验收或发布完成。每卡的“仍要做”均指后续实现任务，本规划只把承诺写清。
- **完成判据（oracle）**回答怎样观察正确结果、怎样反证失败。文件存在、字样命中、回传字段齐全和状态行覆盖，均不能单独证明语义完成。
- **只报告**限定本次新增质量、登记、语言和步骤检查；保留既有路径、权限、写入及 Git 安全边界。底层检测能报失败，公共检查不因此新增阻断或把缺数据说成成功。
- **P0/P1/P2 小节**是材料选节分层，不是任务优先级。T3保两项可分别核验的语义职责：先定候选节与读者，再对同一候选集定分层与模板表达；P0由该类产物的权威声明确定，P1/P2 按任务选择并说明依据，不另建一套固定清单。
- **共享写冲突**按真实文件处理。同批同路径一个写入者；跨批同文件允许按依赖交接，不能用“一文件永远一个任务”否定独立结果。沿 ADR-0038，不把写集声明升级为许可。
- **外部采用**指在既有文件内吸收具名内容；采用登记不证明生效。T11 负责54条不丢失，接收卡负责实现，实际文件由下表归口者集成；不复制成第二套账本。

### G1：每张卡都必须做减法并验证成本

每卡声明删除、合并或降档了什么；只加规则而未简化既有物，不算达到 G1。每卡相对其开工时读取的当前基线核受影响方法、模板和常驻/必读字节不增加；T3 另须材料总字节下降且下游不回改。不得用搬到未统计文件、丢失约束或改分母支付减法。

主 Agent 指标四组分列：`wall_s`；`input/output/cacheRead`；`steps/turns`；`subagent/bash` 调用数。字段缺失或解析失败记 unavailable，provider 未报 usage 记 not_reported。审查 provider token、材料字节与主会话 token 分开，不能互相替代；常驻字节也是代理量，不等于宿主实际总注入 token。

复测使用同任务、同命令、同条件、同预算，报告次数和波动。T0提供复测能力与自身样本，各卡自行负责本卡前后收益；T0的完成不等待其余十一卡全部验收。沿 AC-012：`cacheRead` 与 `wall_s` 均不劣化，`steps` 或 `cacheRead` 至少一项下降。审查收益沿 AC-005 先声明同一 cohort、连续 N≥3；失败与不可用留在分母，质量信息不足时不宣称裁剪安全。方向审查配对和宿主全局注入面不在可削减范围内，不能靠排除它们伪称整体收益。

<a id="shared-detail"></a>

### 共同的执行与失败合同

本节是各卡16字段的公共部分，不替代每卡增量。

1. **正常与空输入**：先读当前决定、实际consumer和允许写集；输入为空、来源打不开或结构不支持，返回具体缺项。检测发现业务/文档问题与检测器自身未运行分开；unknown不填0，缺数据不报通过。
2. **失败与取消**：保留原命令、退出码、原件及覆盖面；取消停止受影响调用并交代已发生动作，不补写完成。审查provider失败按现有路由和生命周期处理，不因达到某个来源下限或任意时长取消其余请求。目录、权限或凭据的真实不可用按现行停机规则报告，其余安全工作继续。
3. **写入与竞态**：正文用现有safe-write；共享记录用现有record-lock。并发改同一材料时先读回差异再按owner交接，不能用后写覆盖前写。重复执行先比较内容和已有原件；同字节复用引用，不造副本、状态序列或恢复许可。
4. **授权**：业务仓写入以既有登记资源/写集为边界；父任务和兄弟材料只读。已有实施授权覆盖的正常Git交付沿现有record/consume核当前HEAD；最终close取得一次真实确认。缺授权不写、也不把安全拒写冒充功能失败；本PRD本身不提供这些授权。
5. **验证与撤回**：负例只改具名fixture或受控副本，验证后还原并确认真实工作树未受扰动；禁止目录快照。受影响定向测试之外不扩全仓回归；本PRD没有启动代码测试。采用无效时撤回该增量并留失败原因，不覆盖旧原件或减弱oracle。

<a id="review-contract"></a>

### 审查投入怎样决定

T5以真实 `git diff --name-only` 产生改动范围，以 `git diff --numstat` 分列新增/删除量，影响面列具名直接consumer、下游调用边及关键路径事实；不能用净行数相抵，也不能以文件后缀或“是否文档”代替影响面。三维有任一项缺失或判断无法复现时，保守回到每Phase审查。

组合先使用同一组已冻结样本做单调排序：其他两维相同，范围/大小/影响增加不得降低审查投入；不凭空设“几个文件/几行免审”。只有在同cohort的真实对照证明某类低投入选择未降低已声明质量判据时，才把该组合写入既有review-policy的选择表。选择表无覆盖的输入继续每Phase审查，不建动态评分器、学习状态或自动降权。终末仍完整审当前交付并并列声明写集与实际diff。

当前明确定下的减法是make-decision/detail取消配对，direction保留；每provider在该轮只调用一次。轮数、来源数和并发数分开：当前文字“收到3条”与配置owner实际派发全部显式配置不一致，T5由现有配置owner统一文字和消费语义，不加selector；本次完整稿审查沿当前已配置路由，不临时裁掉一路凑数字。

D-015的其他候选明确处置：既有diff压缩可接入，但上下文/合同不得丢；不采纳“达到异源下限就取消其他请求”、对冲新路、任意超时或配额截止。推理预算由T5在同范围可回放成本—发现曲线建立后评估；输入上限只有投递口径校准且协议同批调整后才可设计，超限须明确unavailable，不能截断。现在不承诺未测数值或自动生效，当前无上限语义保持。

每卡验收包含其16字段的局部oracle及[G1](#g1)，保留实施、测试、独立审查、交付各自状态。下面列出的命令/调用均为后续验收设计，非本次执行事实；Phase开工时用当前真实路径填写参数和确定目标集合，不把占位参数当已可运行。
