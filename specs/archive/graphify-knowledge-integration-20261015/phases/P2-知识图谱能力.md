### T002 — 提供可搬运知识能力

- **输入**：P1 实际成因、当前 worktree realpath、graph.json、manifest 与原 semantic cache；操作者提供查询问题，文档更新提供候选文档的实际旧/新内容对应和真实成本许可。输入在调用前取得，不能先抽后问。
- **文件 / 符号**：`skills/knowledge-graph/SKILL.md`、`skills/knowledge-graph/skill-bundle.json`、`skills/catalog.yaml`、`graphify-out/.gitignore`、`.gitattributes`、`docs/architecture/move-map.json`；N/A — 非代码方法/登记，不新增 runtime 符号。第一处改动是知识技能四动作契约，随后 bundle 与 catalog 接线。
- **输出 / 失败**：现有 catalog 能唯一找到技能且 bundle 可读取；正常查询返回有来源的结论，缺工具/坏图保 unavailable，文档未批保未更新；冲突与缓存错位不伪成功，按恢复段回原 owner。

- **依赖**：T001。
- **场景 / 夹具或服务**：执行者创建无图/坏图/正常图三个临时项目，工具 stub 分别返回真实 CLI 的无匹配、歧义、无工作和失败输出；真实图作为只读正常输入。付费许可拒绝、prompt 变化但内容不变、同 ID 双改作为反例；只清本次新建临时物，保留原始失败输出。
- **预写测试**：主会话在 build-plan 预写 `tests/contract/knowledge-graph-skill.test.mjs`，graph_repair 执行真实三目标 RED；冻结后不由实施作者改断言。
- **可观察接缝**：catalog → knowledge-graph bundle/SKILL → 五阶段主会话与 P3。当前新接缝 unverified：`npx vitest run tests/contract/knowledge-graph-skill.test.mjs` exit=1，三目标断言证明注册、属性与忽略策略尚缺；P2 owner 实施后用同命令及独立实际调用复验，当前 AC 子条件未通过。
- **执行 owner / 时点**：build-code 的 P2 实施子代理写方法；非实现者在本卡结束前执行正常/负例。独立用户效果与全系统 AC 由 P8 负责，不能用注册成功代替。
- **动作**：先按既有 `schema_version: 1`、`skill`、`files` 填知识 bundle，并在 move-map 登记四个新技能文件、四个冻结测试和本卡两份版本管理策略的职责；consumer 分别沿五阶段/共享收口调用者、相应 Phase gate 和 Git/知识技能读取，替代关系沿现有 graphify 包装且无新 runtime 层，删除须真实零消费和独立审查。冻结测试只可经 TCR 改评分，不因登记获得修改权。再写建图/查询/更新/降级四动作。限定 source_file 为唯一来源，外部引用无来源属可解释结果；语义 label 必须回原文，社区占位不用作导航。强制 `--no-label`、realpath、`Path` 类型 prompt_file，禁止 `--mcp` 和记忆功能；可解析即使用，不加版本门。先查图再定向读源；代码与文档更新分别报告，缺工具/坏输出保 unavailable 继续；退出 1 仅在确证无工作时解释，3/4 列歧义/无匹配。
- **增量与费用**：只有已证明图实际持有的旧内容版本才能盖 manifest；当前磁盘 hash 不等于已抽取版本。候选取“内容变化集合 ∪ 当前 prompt/mode 下缓存未命中集合”，不能只依赖不含 prompt 指纹的 manifest 增量检测。优先同内容、同 prompt/mode 的原缓存重放；无指纹旧缓存 vintage 保 unknown，不静默当最新，不重抽无变化且当前缓存命中的文档。付费候选先列数量/范围、计算依据和区间/不确定性，再等真实许可；拒绝后文档图保未更新，代码图可继续。
- **冲突**：`.gitattributes` 只为 graph.json 声明 `merge=graphify`。手动 merge-driver 只作 current/other 并集，不声称三方语义合并；同 ID 双改与删除以两方原文和实际 hash 人工裁定。manifest 不合并出虚假已抽取版本；semantic cache 同内容同 prompt 可复用，键碰撞异字节保冲突；analysis 只对已核合并图重新计算，强制 `--no-label`。每类读回后再让 closeout 消费。
- **清理**：只清本次调用新建且已确认可再生的具名中间物；不批量删既有 graphify-out/cache，不把整个 ignored 目录当安全清理对象。其余由最终 close 范围展示具名例外。

- **预期退出码**：RED nonzero; GREEN 0。只有具名目标断言失败才算 RED。
