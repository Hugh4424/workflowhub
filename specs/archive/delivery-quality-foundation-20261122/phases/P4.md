## 这一 Phase 交出什么？

阶段审查者看到真实写集差异，步骤检查者按真实文件、类型和身份判断完成。

- **本 Phase 结果**：包3三入口对账与包5声明读取各自可独立验证，并按序交付。
- **非目标**：不新建统一读取层、对账器、公共命令、持久状态或第二进度账。
- **改动前**：对账入口缺真实参数，目录、标签和生产者自述可能掩盖缺口。
- **改动后**：可比路径显示真实差异，声明按实物判定，不可比与缺件保持可见。
- **与相邻 Phase 的边界**：消费 Phase 3 检查器，向 Phase 5 交回运行时和终末链。
- **主要风险**：把裁后名单当全集或目录当完成；出现时停对应包并撤该接线。
- **下一步**：Phase 5 接发布与终末校验，Phase 6 保留已接 `change-scope`。
- **动手前必读**：`quality/evidence/decision-maker/p03/design.md:40-90`。
  再读 `p05/design.md:44-138` 与 `build-plan/light-research.md:5-9`。
- **未决事实**：无合同目录的逐条形态由步骤 owner 补；未答条只作导航。
  授权别名与 `--report` 去留由对应 owner 核真实调用，不能静态猜删。

## 这一 Phase 怎么验收？

本 Phase 承接 spec 的验收4与验收5，判据分别以 AC-SCOPE-001、AC-DECL-001 为权威。
非 UI：不适用——本 Phase 只改 Git 范围、任务事实和命令行检查，没有页面改动。

- **成本账**：AC-SCOPE-001 为30活动分钟，AC-DECL-001 为35活动分钟。
  串行合计 `acceptance_cost_total=65 active_min`，均为未校准估算。
  `phase_budget=unknown — 无已校准基线`。
- **资源账**：真实 Git 工作区、Phase 起点、步骤表、任务事实和现有检查器。
  受控改动与错误声明可在隔离工作区就地构造；不得注入伪造全集或空文件凑绿。
- **范围账**：任务4证写集对账，任务5证声明读取；彼此原件是供件，不混写完成条件。

**验收4：写集对账只报告真实事实**

目标是三个生产入口收到当前 Phase 身份与裁剪前范围，并让消费者读到同一事实。
操作时构造匹配、漏报、多报，再移除参数、起点或完整范围。
条件是真实工作区、合法 Phase 起点和授权读取面；受限、跨库路径不得扩权。
故意实改 a/b 而只申报 a，必须看到 b 漏报；裁后只有 a 不得报匹配。
读域不足或 Git 采集失败也必须进入同一不可用断言，不能只在输出说明中出现。
真跑命令见任务4；独立测试者与阶段审查读者在包3实现后判定。
失败回包3原开发；误用任务起点、改变退出或越权读取即停止该入口接线。

**验收5：步骤声明与实物按类型对齐**

目标是固定件、动态件、方法字段与两个收敛 reader 使用同一语义。
操作时删固定件、改错 kind、错任务、多引用，并用同一清单跑两个入口。
条件是七张步骤表、真实任务事实、唯一义务表和合格原件可读。
故意把 review 改成 test，必须转入命令捕获判定并失败；多引用不得取最新。
真跑命令见任务5；独立测试者与三阶段方法读者在包5实现后判定。
失败回包5原开发；缺合同条只保留缺口，其它安全工作继续。

## 怎么验证？

测试面是运行时纯函数、命令行合同与真实任务事实，主技能预判为 backend-testing。
两个工作包分别预写目标测试，不共享 RED/GREEN 证据或写夹具。

任务4命令：
`npx --no-install vitest run tests/contract/stage-write-set-reconciliation.test.mjs tests/contract/build-code-change-scope.test.mjs tests/contract/build-code-readiness.test.mjs tests/contract/n11-plan-quality.test.mjs`

两命令 RED 都由具名目标断言非零，GREEN 用原命令期望0。
手工 oracle 分别先写 a/b 对 a 的漏报预期，以及 review→test 的命令捕获失败预期。
真实捕获保存实参、cwd、退出和原输出；隔离改动同进程创建、消费和清理。

覆盖上限：只证三入口和声明读取，不证安装、风险接受、退役或最终全量对象。
显式不覆盖真正跨库比较、无合同目录的猜造文件和在线审查服务。

失败时分别回包3或包5原开发，保留原失败与历史字节。
回滚只撤对应工作包 hunk；不得恢复目录自动发现、裁后冒充或缺字段静默通过。
