## 仍未闭合的可观察边界

此前只给 `spec.md`、`phases/index.md` 和 `P2.md` 的独立冷读反馈是：能指出 T007/T010 的文件、命令、正负例与 STOP，但**不能开始共享生产修改**，仍需确定候选 ID/同义组、研究交付、轮次事件/自检、假设版本的字段与读写关系。该反馈是本报告的既有抽验记录，本轮未重新组织实施者，也不能替代 P4/T020 要求的 P1～P4 当前版本逐包冷读。现有 spec 的“行为验收的可观察合同”与 P2 的 seam preflight 已把缺口和责任写明，却明确称其为先决接口设计、非已有 runtime 能力。[当前 spec.md:382-394](../spec.md#L382-L394) [P2.md:31-37](../phases/P2.md#L31-L37) [P4.md:101-123](../phases/P4.md#L101-L123)

1. **结构可检不等于语义可执行。** 当前 decision-log 的逐字 U/V/原子条目已由正式 reader 独立恢复，R 只作映射；当前样本去重后分母 37、索引错误 0，原文单元有字节位置/hash。identity-bound post profile 拒绝自报相同预期/实际取得 `consistent`。但原子条目是否保留父级原句含义尚需独立语义审查；官方 runner 仅执行 JS profile 并记录 skill ID/hash，尚非独立 lens verdict。故 ID、文件数、结构 GREEN 不能推导 AC-54 已达。[当前 spec](../spec.md) [P4](../phases/P4.md)
2. **模板、填充卡、目标 RED 是三层。** spec-template 与 phase-template 已要求来源定位、正反 oracle、预写测试、可观察接缝、RED 证据和变更请求；P1～P4 共 20 张卡现都有相应字段。但多数卡的测试文件和实际 failing assertion 尚待预写/捕获，字段里明确写待验证。正式 `no_prewritten_test` 的 testFacts/文件 hash/目标断言绑定也未有完整当前证据。不能把模板合规或计划路径算作有效 RED、生产 GREEN。[spec-template](../../../skills/spec-specify/templates/spec-template.md) [phase-template](../../../skills/spec-plan/templates/phase-template.md) [P1](../phases/P1.md)
3. **可观察业务 seam 仍是设计前置。** AC-33/34/36/38/42 所需 producer、记录字段、reader、来源分母和缺失语义在 spec 中有提案，但同段明确“非已有 runtime 能力”，P2 也要求先冻结接口再预写真正读取产物的目标 RED。只测文案、局部 `research-report.v1`、问题卡形状或 OI 终态不证明业务 AC；未冻结的部分保持 `incomplete`。[当前 spec.md:382-394](../spec.md#L382-L394) [P2.md:35-37](../phases/P2.md#L35-L37) [P3.md:30-38](../phases/P3.md#L30-L38)
4. **OI-016 时间边界已在文案中纠正，但事实未冻结。** decision-log 保持 `deferred`、`requires_user_decision: true`、trigger=`build-plan 前（不晚于 build-code）`；当前 spec/P2 已明确在声称 build-plan 被接受前完成文件/符号交集、唯一 owner、接口版本、顺序、集成责任与确认，不再仅说“生产编辑前”。在真实冻结/对齐记录缺失时，只能做不触碰共享写面的只读核对/fixture 准备，不能称 build-plan 质量完成或 P2 共享编辑无条件可做。[decision-log.md:746-760](../decision-log.md#L746-L760) [当前 spec.md:403-404](../spec.md#L403-L404) [P2.md:31-37](../phases/P2.md#L31-L37)

## 可交付判断

作为**执行前工作包**，当前 CARD-07 的四个独立 Phase、纯指针 index、全局 spec 与两份模板，比首版 post 具有更清楚的导航和防遗漏合同；但旧 CARD-02 的执行前 `spec/plan/tasks` 也有扎实的接口、测试与逐卡执行设计。目前只能评“结构与来源保真局部更强”，不能评“填充材料的开发指导力明显更好”。仍需 P2 业务可观察读写接口、逐卡预写测试和有效 RED/GREEN 的 canonical 原件、最终独立语义审查/阶段读回、OI-016 冻结，以及 P1～P4 的独立实施者冷读。原 CARD-02 22 条 AC 逐项有同义实现与真实质量证据、且新模板和填充材料明显优于旧执行前工作包，才满足 main 提交前提；本报告不作该裁决，也不触发提交。缺项继续保持 `incomplete/unavailable/unknown`。[当前 spec](../spec.md) [P4](../phases/P4.md)
