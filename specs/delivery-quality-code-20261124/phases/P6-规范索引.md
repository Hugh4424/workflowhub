# Phase P6 — 规范索引

本卡交给阶段 6 专属作者、独立审查者、独立回读者与阶段 7 作者。
“域”是设计、前端、后端、接口、验收、代码改动与外部引用这类规范分组。
“规则表”是每域入口里一张五列表：规则、正文锚点、靠什么强制、状态、什么时候读。
“指针”是 AGENTS 里一行“去哪找”的链接，不是规则正文。
“三句钩子”是四个读点各写：命中哪条、因此改了什么、为什么没命中。
本阶段不是纯文档：写集含结构检查器代码，按行为契约判红绿。
本卡按 `skills/phase-maker/SKILL.md#八步` 写；精确命令按原字保留。

## 这一 Phase 交出什么？

一句话：规范按域住进 specs，AGENTS 只留指针，四个读点说清命中与改变。

- **本 Phase 结果**：九个新文件与三份 README 有五列表；AGENTS 每域一行；
  结构检查抓空链接与错锚点；四个读点各三句；前端消费者同批改入口→正文。
- **非目标**：不建独立经验库、不把规则表塞进 AGENTS、不复制技能正文；
  不改 `specs/Improvements.md`；不新增阶段、门或进度对象；不建空文件凑数。

- **下一步**：P7 作者读九个域入口与四个读点，写收口与退役承接。

- **保留无关工作**：已建好的九文件、已通过的其它判据、同文件其它任务改动保留；

  回退后重放同一验收。
