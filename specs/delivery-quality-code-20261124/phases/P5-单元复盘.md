# Phase P5 — 单元复盘

这一阶段只干一件事：让每个单元做完时当场留一条五问复盘记录，并让五个技能各有一个
可被逐字断言的固定节。读完这张卡的人应当能直接开工、能独立验收，也能把它交给
P1、P3、P6、P7。

## 哪些节必须写，哪些可以省？

模板必填节全部在场；phase-maker 逐 Phase 的调研、设计、任务卡、回读对象各占一节；
写作脚手架不落盘。

| 节 | 本文件怎么处理 |
| --- | --- |
| 怎么写（八步两层） | 写八步在本阶段的实际动作与落点 |
| 本 Phase 调研结论 | 写结论、来源与它改变了哪项设计 |
| 交出什么 | 写结果、非目标、前后对照、边界、风险、未决事实 |
| 首卡纵切 | 写公开入口到失败信号的一条链 |
| 首卡开工五列 | 写两条：读回与负例 |
| 外部供件登记 | 写用途、期限、超时错误、来源 |
| 未知半径 | 写未知影响、卡号、验收编号、退回谁、哪条可能失效 |
| 怎么验收 | 写三账、六段验收、回退保留、非 UI、预算 |
| 为什么现在做 | 写现状证据与上游决定 |
| 开始前读什么 | 写八份材料与读序 |
| 每个文件由谁改 | 写 NEW／MODIFY 与前后写者 |
| 每张任务卡怎么写 | 写六张卡，T029 至 T034，一卡一条判据 |
| 怎么验证 | 写三层命令与替代说明 |
| 下一消费者拿什么继续 | 写交给 P1、P3、P6、P7 的可观察件 |
| 机器字段 | 写文件级十个标签 |
| 末验专属检查 | 不写，本阶段不是唯一末验阶段 |

## 这一阶段怎么写（八步两层）

八步分两层：第 1、2、3、7 步是全局动作，由计划负责人做一次；第 4、5、6、8 步
逐 Phase 各做一次。本卡交第 4、5、6 步的产物，第 8 步交出被审与被读的对象。

| 步 | 层 | 本卡动作 | 落点 |
| --- | --- | --- | --- |
| 1 读输入 | 全局 | 读决定、规格、任务库设计与五份技能现状 | 「开始前读什么？」八条 |
| 2 定全局设计 | 全局 | 不重写，只回指并照它的接口与文件边界执行 | 机器字段「全局规格」 |
| 3 切 Phase | 全局 | 按一个可独立验收的结果切：五节可读、一条记录五问齐 | 本节与「交出什么」 |
| 4 每 Phase 调研 | 逐 Phase | 真读复盘技能现状、四技能末节、四份步骤表与测试文件是否存在 | 「本 Phase 调研结论」 |
| 5 每 Phase 设计 | 逐 Phase | 写契约头与写集：增量、回指全局锚、逐路径 NEW／MODIFY | 「每个文件由谁改」 |
| 6 每 Phase 写任务卡 | 逐 Phase | 六张卡一卡一条判据，各写首读符号、首改路径、先失败、反例、恢复 | T029 至 T034 |
| 7 渲染索引 | 全局 | 索引由计划方渲染；本卡只留指针与摘要 | 机器字段「写入集」 |
| 8 独立审查与回读 | 逐 Phase | 本卡只交出被审与被读对象；四问结论与六问作答由另两位执行者产出 | 「下一消费者」 |

**三份原件**：本卡是专属作者交付件；独立审查者的四问结论与独立回读者的六问作答
由另两位执行者产出，缺一份本 Phase 不算完成。同一人不得兼作者与审查者或回读者。

## 这一 Phase 交出什么？

单元做完当场留一条五问记录：五个技能各有固定节，记录写清五问与证据指针，
聊天里先发五条以内摘要；阶段末只汇总，不重做。

- **本 Phase 结果**：五份技能各有可逐字断言的固定节；新建合同测试断言五节名与
  五问字段；一份真实记录五问齐且指针可打开；记录里有「命中」与「首次」各一例，
  P6 表未交付时标「待补」；聊天有不超过五条摘要加记录路径；复盘没有被写成门。
- **非目标**：新建一个「沉淀读取」技能，可做但本次不选，用户已明确否掉，
  且多一个读者、多一个家（决策日志包 5 第 3 项）。
- **非目标**：只在阶段末统一复盘，可做但本次不选，教训会遗失、现状已证明没人用。
- **非目标**：建域规则表结构与列名，可做但本次不选，表归 P6；
  本阶段只在记录里写三种状态词（决策日志包 5 第 5 项）。
- **非目标**：扫历史任务、计次数、判复盘内容好坏，可做但本次不选，
  用户已定只看当前任务加域规则表（R-024、R-009）。
- **非目标**：把七步流程锚与产物判据写进本包，可做但本次不选，
  那些归 P8、接线断言归 P9（决策日志包 5「审查后更新」）。
- **改动前**：复盘技能只有阶段收口四节；四个单元技能末节无复盘收尾；
  `decision-maker` 只有 `:421-422` 一句 owner 级复盘；四份步骤表都写
  「Phase 摘要不另触发」；最近七个任务没有一条 `quality/evidence/reflection/` 记录。
- **改动后**：五份技能各有固定节；一份记录五问齐且指针可开；摘要不超过五条带路径；
  四份步骤表与 `build-code:174` 改说「单元复盘是 Phase 内动作，不新增阶段门」。
- **与相邻 Phase 的边界**：本阶段无上游、是先行包；下游 P1、P3、P6、P7 读本阶段的
  记录口径、状态词与节名；本阶段不写规则表、不写流程锚、不做接线断言。
- **主要风险**：复盘写成形式——只添「复盘」两个字、只写建议、指针打不开。
  若因它返工，替代走法是先只落合同测试与五问字段，再补四个技能的收尾文字。
- **回退保留**：只撤新增节与合同测试的文字改动；已写记录按历史只读保留，
  不删已写记录、不覆盖他人条目；原始失败原件（RED 捕获、读回记录）不动。
- **下一步**：P1 与 P3 读节名与记录口径；P6 建规则表时只补列、不改记录格式；
  P7 只读记录里的晋升、驳回、未执行三组字段。
- **动手前必读**：按读序排在「开始前读什么？」一节。
- **未决事实**：`build-plan:253`、`build-prd:73`、`make-decision:430` 三处同句不在
  本阶段写集。影响：四份技能口径可能不一致。处置：本阶段只改 `build-code:174`；
  余下三处保留原文（语义仍成立），要统一措辞由写集 owner 扩写集或留给 P4。
  退回谁：索引作者与四卡作者；恢复条件：写集扩写后同批改。
- **未决事实**：P6 规则表结构与列名未定。影响：记录状态列只能写三种词，
  不能写表里没定的列。处置：只写「命中」「首次」「待 P6 表」；表交付后由 P6 恢复
  状态列，本阶段不建表。
- **未决事实**：近七个任务没有一条复盘记录，本阶段没有既有样张。
  影响：验收 3、4 要的真实记录得由本阶段写第一条。处置：按新节写本任务第一条记录，
  放任务根 `quality/evidence/reflection/`（属证据、不进仓库写集）。
- **未决事实**：四技能是否真被调用仍由 P10 真实使用者验，接线断言归 P8、P9。
  影响：本阶段只证到「节在、记录在、摘要可见」。退回谁：P8、P9、P10 作者。
- **未决事实**：本任务起始用户事件原件未取得，成本只能记「未取得」与原因。
  退回谁：计划负责人；恢复条件：拿到原件或用户明确不建首笔后重记该行。

## 这一 Phase 怎么验收？

先算三账，再按一条一小段写六段；判据正文只在附录写一次，本节只引。

- **成本账**：六条判据的成本七字段取自 Appendix A 包 5 每条的成本行。
  估算 8+8+15+12+10+20＝73 活动分钟；硬上限 20+20+35+30+25+45＝175 分钟；
  共享准备 5 分钟；重试预留 8 分钟（每条重试上限 1）。活动总额 86 分钟；墙钟单列。
- **资源账**：五份技能、四份步骤表、`build-code` 当前字节（仓库自带）；
  一条按新节写的真实记录（本阶段写第一条，落任务根证据区，不进仓库写集）；
  当次会话记录；合同测试回执。每条段内标来源，不新造样本。
- **范围账**：验收 1、2 证五节与合同测试；验收 3、4、5 证记录与聊天可见性；
  验收 6 证复盘不是门；跨阶段只写「供件」。

`acceptance_cost_total=86 active_min`
`phase_budget={soft_min:120,hard_min:240,variance_threshold:1.5,source:provisional}`
