# Phase P4 — 自动作业方法接线

这一阶段把「自动作业要验到处理段、无权发送要在发出去之前由接收侧确认没收到」
写进测试方法、施工流程与简化审查；这次只写方法，不装后台、不连真实服务。
读完这张卡的人应当能开工、能独立验收，也能把它交给 P6 作者。

## 哪些节必须写，哪些可以省？

模板的必填节全部在场；只属于末验阶段与写作脚手架的节不落盘。
本卡对应 phase-maker 八步：第 1 步在「开始前读什么」；第 2、3 步由 spec 与决策日志承接；
第 4 步在本节调研表；第 5 步在「契约头与写集」；第 6 步在六张任务卡；
第 7 步在纯指针索引；第 8 步在「下一消费者拿什么继续」。

| 节 | 本文件怎么处理 |
| --- | --- |
| 交出什么 | 写结果、非目标、改动前后、调研表、契约头与写集、首卡纵切、五列、供件、半径、回退 |
| 开工就绪表 | 写五列增量行，含指纹与三份文件在场核对 |
| 怎么验收 | 写三笔账、六段验收、非 UI 声明与预算 |
| 为什么现在做 | 写现状证据与顺序依据 |
| 开始前读什么 | 写八份材料与读序 |
| 每个文件由谁改 | 写三个文件、首动作与共享写者 |
| 每张任务卡怎么写 | 写六张卡，任务 1 至任务 6 对应 T023 至 T028 |
| 怎么验证 | 写命令面与人读面 |
| 下一消费者拿什么继续 | 写交给 P6 的可观察件与回读协议 |
| 机器字段 | 写文件级十个标签 |
| 末验专属检查 | 不写，本阶段不是唯一末验阶段 |
| 写作脚手架与示例 | 不写，它们是模板作者自用的草稿，落盘即删 |
