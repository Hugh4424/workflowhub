本节描述写卡阶段的派发预算；执行阶段按内核 R2 的角色（一开发一审查一测试）另外计，不并入本节。

每个 Phase 最多三次派发（写卡阶段）；超过三次要在本卡写明理由与代价，不默认增加。

- **三次派发各做什么**：第一次把调研与设计合并（读材料、给方案、写初稿）；第二次落卡（按初稿写卡并自检）；第三次一次性审查（独立读者只判目标是否对齐、验法与反例是否成立、写集是否越界，不重写）。
- **哪一次与别的阶段并行**：并行面以本卡「与相邻 Phase 的边界」与 `spec.md` 的「谁先谁后？」为准；本卡在该节写明与谁并行，不并行写理由。
- **超过三次要写理由**：本卡写清为什么必须多派、多派的代价与谁批准；写不出理由就不增派。
- **审查只一轮**：同一 Phase 只开一轮独立审查；修复回原派发，受影响方复验，不另开第二轮。
- **回读不属于派发预算**：回读按 `skills/phase-maker/SKILL.md` 的「回读契约」单列，不计入本节次数。
