# Phase P7 — 阶段收口与退役

这一阶段只干三件事：给交接加一行「阶段复盘」、把八条旧规矩逐条退役并写清承接、
把 `core/task-close.mjs` 的私有任务类型解析改调共享。读完这张卡的人应当能直接开工、
能独立验收，也能把它交给 P8。

## 哪些节必须写，哪些可以省？

模板必填节全部在场；phase-maker 逐 Phase 的调研、设计、任务卡、回读对象各占一节；
写作脚手架不落盘。

| 节 | 本文件怎么处理 |
| --- | --- |
| 怎么写（八步两层） | 写八步在本阶段的实际动作与落点 |

## 这一 Phase 怎么验收？

先算三账，再按一条一小段写十段；判据正文只在附录写一次，本节只引。

- **成本账**：十条判据的成本七字段取自 Appendix A 包 7 每条的成本行。
  估算 6+10+6+20+35+15+5+5+12+8＝122 活动分钟；硬上限 302 分钟；
  共享准备 8 分钟；重试预留 12 分钟。活动总额 142 分钟，超软上限 120、
  低于硬上限 240；不拆分，重试与准备各计一次。
- **资源账**：两份方法、八条退役涉及文件、真实交接件与复盘记录目录、退役批准原件、
