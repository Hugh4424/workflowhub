### D-006 验收 oracle：三件 oracle + 双通路 + G-2 可失败检查

- question/final_option：AC-07/AC-08 要求的「真实实施 task 样例」从哪来？本卡的 oracle 由什么构成、怎么防止「自己验自己」？／final_option=卡内造最小真实 fixture task + 检查工具 RED→GREEN 双通路 + G-2 补可失败检查
