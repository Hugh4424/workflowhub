## 这一 Phase 交出什么？

计划作者能算清每条验收由谁做、花多久、靠什么和如何观察。

- **本 Phase 结果**：成本七字段与 Phase 活动总账可独立重算，超限有真实处置。
- **非目标**：不新增预算账本、机器退出门或全任务轮次上限。
- **改动前**：模板只有约分钟和剩余预算，缺统一七字段与并行汇总口径。
- **改动后**：逐条成本、共享准备、重试预留和用户等待分别可读。
- **与相邻 Phase 的边界**：前序已交步骤合同，本 Phase 补成本，后续再补执行控制。
- **主要风险**：把墙钟或用户等待算进活动执行；出现时按分项原账重算。
- **下一步**：控制作者复用预算字段，另写实现执行预算，不与验收成本混算。
- **动手前必读**：`spec.md#实现设计全局权威`、两个现有模板和历史回放件。
- **未决事实**：阈值仍待校准；用户与计划作者取得误停、漏停表后再确认。

简化决定是扩展现有模板和验收计划测试，不新增校验器或持久预算对象。

## 这一 Phase 怎么验收？

本 Phase 只首判验收 8，最终聚合不在此重复首判。
三笔账如下，分钟都是临时估算，不是执行读数。

- **成本账**：两张卡串行三十五加二十五分钟，共享准备三十分钟。
  一次受影响重算预留三十分钟，活动执行合计一百二十分钟。
- **资源账**：复用当前规格、现有模板、合同测试与历史只读材料。
  独立读者来自不同上下文，用户只处理阈值或超硬上限确认。
- **范围账**：只证成本七字段、Phase 公式、等待分账和超限拆分。
  历史业务结果与其它 Phase 的实际成本只作供件，不在此承接。

七槽如下。

1. **验收标准**：独立读者能重算当前规格至少两条验收及一个 Phase 总账。
   成功是七字段、资源来源、首末判时点、活动口径和超限处置齐全。
   失败是只写预算内、等待混算、缺成本仍入 Phase 或超硬上限无确认。
2. **场景**：正例用三十加并行六十与四十五取最大，再准备十、预留十五。
   结果为一百一十五分钟，低于临时软上限一百二十分钟。
   反例一总账二百五十五分钟，必须展示并取得真实确认。
   反例二缺执行者或资源字段，不能进入 Phase。
   反例三把十一条历史验收塞回一个末段，必须拆便宜与真实环境两段。
3. **环境与数据**：本机文本读取、当前规格与模板、历史只读原件。
   开发提供模板和算例，独立读者提供重算与读回结论。
   临时算例只存在测试夹具，测试后清理；重算和读回原件保留。
4. **用例**：用例一核七字段、并行公式、软上限和缺成本拒绝。
   用例二核二百五十五分钟的确认要求与末段拆分。
   用例三并列研究汇总 448 分钟、241 命令、86 非零，
   与执行清单 235 命令、80 非零、433.2736 分钟墙钟跨度。
   两者冲突不得统一；活动执行成本保 unknown/incomplete。
   用例四核历史末段拆为便宜八点八分钟与真实环境二十五分钟；
   研究估算三百六十至四百八十分钟不是实测，缺失项不得补数。
5. **谁判**：独立读者重算，独立测试跑模板合同，均异于开发上下文。
   时点为开发完成且审查发现修完后；输入为真实模板、规格与历史原件。
6. **失败回修与重验**：模板断言失败回本 Phase 开发，历史缺件回原件提供者。
   修后只重跑受影响算例和读回，由原独立判定者按新原件重报。
7. **承接**：首判结论和缺口进本 Phase 完成字段与计划证据路径。
   最终验收者只读这些原件，不能以模板存在代替成本语义判定。

**效果判据**：未参与写作的独立读者只拿规格、Phase 与历史原件，
能指出每项成本来源、重算总额并说明为何拆分；需要作者补数才算失败。
当前第六阶段超硬上限风险必须展示，不得为塞进预算删判据或伪报分钟。

`acceptance_cost_total=35+25+30+30=120 active_min`。
`phase_budget={soft_min:120,hard_min:240,variance_threshold:1.5,source:provisional}`。
实现执行另记 `execution_budget={window_minutes:120,command_cap:50,wait_cap:30,retry_reserve:30}`，不与验收成本混算。
阈值或超硬上限的用户等待按单路径十五分钟临时上限单列，不计活动执行。
独立重算不需要审查提供者；若另有审查，其等待单列且不套通用上限。

## 怎么验证？

本 Phase 开发与审查结束后，按 P3 的执行协议派至少两个独立只读测试代理并行执行本 Phase 的 AC；
代理不共享写文件，主会话合并结果，冲突保留；普通测试失败和代理冲突不问人，只有 AC/范围、
缺外部原件/凭证或不可逆动作才停。

模板合同用同一命令先证目标缺项，再证同一算例通过。
纯文档历史回放不制造 RED，以独立重算和读回作客观替代。

| 成本七字段与 Phase 公式 | T003 | GREEN | 同命令退出 0 | ORACLE-P2-COST；`quality/tests/P2-T003-green.output` |

覆盖上限：只证成本口径、模板算例和指定历史材料可重算。
显式不覆盖：历史业务通过、未来真实执行分钟、阈值已经用户确认。

- **风险**：为符合软上限删验收、把研究估算当实测或把等待算进活动执行。
- **影响**：预算误停或放行，用户看不到真实成本，后续停止规则失真。
- **缓解**：逐字段重算、并行公式、缺失保 unknown、超硬上限真实确认。
- **回滚**：原开发只撤本卡相关模板或测试 hunk，保留其它改动和原失败。
- **补救与交接**：历史缺件回历史原件 owner；产品判据变化回原决定 owner。
- **触发条件**：缺成本仍入 Phase、超硬上限不确认或末段重新合并全部验收。

完成判据要求模板合同、独立重算、历史读回与确认缺口均可定位。
结构测试退出 0 只证模板可读，不代替验收 8 的语义结论。
