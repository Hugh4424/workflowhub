- **一句话需求**：维护者要把失败且昂贵的 M15 监控体系从 workflowhub 生产代码中完整拆除，让框架回归轻量，同时保证正常任务执行与历史数据分毫不损。

- **验收信号**：仓库里搜不到监控模块的任何引用；全部测试与静态检查通过；真实任务照常跑通；历史数据字节级不变；旧页面仍能打开且明确标注已退役。

## 1. 问题与紧迫性

M15 监控体系经历三版返工仍未达到设想：只有 codex 一个 agent 能采到数据、页面内容偏离初衷、且为支持它对运行时做了大量侵入式修改（stage 流程内嵌监控 sidecar、任务事实存储混入监控分类）。继续维护它的成本远超收益，还会误导后续优化决策（"没采到"与"流程没发生"无法区分）。现在必须止损拆除，为紧随其后的离线复盘器任务腾出干净地面。

## 2. 背景、目标与范围

### 背景

- M15 原始设计定位是"消费既有事实做流程退化诊断，不改核心流程"（roadmap 验收："核心目录 diff 非空即失败"），实际实现漂移成了侵入式遥测平台。
- 阶段自记录机制（五阶段流程自身的步骤/结果记录）与 M15 监控链在代码上存在共享文件纠缠，退役必须按功能纠缠边界动刀，不能按文件名一刀切。
- 用户已承诺：本任务交付后（触发条件见 §10 DEF-001 / 决策 D-006）立即启动任务 B（离线复盘器），承接优化洞察诉求。

### 目标

- 监控体系代码从生产运行时中清零，无任何残留引用；
- 五阶段任务执行与自记录能力分毫不损；
- 历史数据与仓外页面安全冻结、诚实标注；
- 基线干净：无关在制品先行入库，拆除 diff 纯净可审。

### 范围内

- 监控采集链、投影链、诊断、页面模板、监控数据 schema、孤儿采集 CLI、空配置 registry、纯监控测试的删除；
- 混测文件与登记表中监控部分的摘除；
- 仓外页面顶部加"已退役"静态提示条（唯一的仓外改动）；
- 主工作区两个无关未提交改动在开工前以独立 commit 提交；
- 删除登记（move-map）同步更新。

## 5. 功能需求

### 退役拆除（RETIRE）

监控体系的全部生产能力从 workflowhub 运行时消失：不再采集、不再诊断、不再投影、不再生成页面。拆除按功能纠缠边界执行，保留区符号不受影响。

- **FR-RETIRE-001**：退役后，stage 流程的任何执行路径都不再触发监控采集、监控事实生成、全局快照重建或页面投影。
  - **范围边界**：包含采集、诊断、投影、页面生成、监控数据格式、孤儿采集入口、空配置 registry；不包含阶段自记录机制（见 PRESERVE 域）
  - **依据**：D-002；PFACT-01
  - **场景**：SCN-001、SCN-004
  - **验收**：AC-RETIRE-001、AC-RETIRE-002
- **FR-RETIRE-002**：退役不给任何 agent 宿主新增或改变数据采集行为；其他宿主本就无法采集的状态保持不变。
  - **范围边界**：不补 DSH/Kimi/Claude 等任何 provider 的采集能力（非目标 5）
  - **依据**：D-001、D-008；PFACT-04
  - **场景**：SCN-001
  - **验收**：AC-RETIRE-002
- **FR-RETIRE-003**：开工前主工作区的两个无关未提交改动以**一个独立 commit（且仅包含这两个改动）**提交，提交哈希与拆除任务基线写入验收证据，拆除工作在干净基线上进行。
  - **范围边界**：只含该两个改动的入库；其内容本身不在本任务评审范围
  - **依据**：D-007；PFACT-05
  - **场景**：SCN-001（基线前置）
  - **验收**：AC-RETIRE-003

### 保留保护（PRESERVE）

阶段自记录机制是被监控链"借住"的第一方能力，退役过程中必须分毫不损。

- **FR-PRESERVE-001**：退役后五阶段自记录功能完整：需求认证、需求快照、步骤/技能执行事件、stage 结果、任务事实的通用读写均照常。
  - **范围边界**：含住在待处理文件中的需求认证/快照子集（保留符号清单以 decision-log 附录 A 为唯一权威）
  - **依据**：D-002；PFACT-01；F-005
  - **场景**：SCN-001、SCN-005
  - **验收**：AC-PRESERVE-001
- **FR-PRESERVE-002**：对 codex 会话事件机制，退役只摘除其 token 用量统计附带行为，事件记录本体不受影响；DSH 宿主下维持既有 unavailable 诚实语义。**本任务不得宣称 codex 宿主路径已完成验证**——codex 宿主完整验证是延期项（OPEN-101，spec 编号空间独立于 decision-log 未决项表），本任务关闭不代表该路径已验证。
  - **范围边界**：仅 token 统计附带行为；事件记录骨架不动
  - **依据**：D-002；PFACT-03
  - **场景**：SCN-005
  - **验收**：AC-PRESERVE-002

### 仓外页面（PAGE）

- **FR-PAGE-001**：仓外监控页面冻结为静态历史快照：数据永久停在退役前最后一次投影，三件套文件不删除。
  - **范围边界**：仓外文件唯一允许的内容改动是 FR-PAGE-002 的提示条
  - **依据**：D-003；T-006；PFACT-02
  - **场景**：SCN-002
  - **验收**：AC-PAGE-001
- **FR-PAGE-002**：仓外页面顶部出现静态"已退役"提示，说明数据已冻结、后续由复盘器任务重建，避免误读为当前监控。
  - **范围边界**：纯静态文本提示，无脚本、无样式重构
  - **依据**：D-003、FND-106；PFACT-02
  - **场景**：SCN-002
  - **验收**：AC-PAGE-002
