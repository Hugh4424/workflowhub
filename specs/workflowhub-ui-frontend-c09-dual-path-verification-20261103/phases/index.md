## 并行与合并导航

P1 先做，卡内顺序按 P1 正文（编号不等于次序）；P2 与 P3 在 P1 后并行；
P4 等 P2、P3 都完成后开工；P5 等 P4；P6 最后。
六份写集互不重叠，跨组只需真实依赖，不需要额外协调锁。
P3 只写仓外旧侧副本，不读 P4、P5 材料；P4 只消费 P1、P2、P3 的真实产物。
P5 的指标表只引用 P1 冻结的定义与 P1～P4 的即时事件记录，不改前者。
P6 是唯一全 AC 验收 Phase，等 P1～P5 全部收口后开工。
