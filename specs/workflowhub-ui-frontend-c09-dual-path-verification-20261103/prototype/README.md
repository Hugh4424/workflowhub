## 可见入口与两种四态

默认冻结示例。模拟记录页顶部工具栏、工作台顶部工具栏都有“数据状态（原型演示）”下拉：冻结示例、正常（本地演示）、正在加载、暂无记录、加载失败、结果未取得。选择后四项进入本地live数据状态演示，不连接真实HTTP/存储/交易。

- 正在加载：真实显示等待界面，2秒后本地示例完成回正常；也可返回冻结示例。
- 暂无记录：明确空数据，点“恢复示例记录”回正常。
- 加载失败：明确读取失败，点“重试”进入可观察等待再回正常。
- 结果未取得：不解释为没有记录或成功，点“重新读取”进入等待后恢复。

各态不显示冻结业务列表/订单/指标冒当前数据；返回冻结示例只复位当前内存。工作台在记录001“打开工作台”进入，“返回”回列表。

运行状态四态另在每个运行卡“更多”底部“演示运行状态”：运行中、行情延迟、恢复中、休市等待。它们不是数据四态。全局“实盘驾驶舱”不是该演示入口、不在两页范围。

待启动卡“更多→取消本次启动”有确认，取消后可恢复待启动。历史/归档需先点summary展开，历史卡有“已废弃”标签，更多→恢复到模拟记录为即时本地动作，无恢复确认dialog。闭合归档不挂载隐藏卡。订单四详情/三tabs/TF选择、停止确认/取消/本地停止中与详情分区均为真实原生交互。危险停止明确不伪造Flat。
