## L0 — 结果与变更

驾驶舱现在是「有人手工拼 pageData 才出页」的离线生成器。本 Phase 让它变成事件驱动的只读派生页。判定它成功只看一件事：不提供手写 `pageData`，只给任务根与真实报告，页面通过req/wp/task三类目录与其有源详情卡消费15类内容和十环，真实对象逐项齐备或短态标缺。15类侧栏或DATA内有对象但无真实内容均不算完整交付。

- **结果**：同一入口在六类真实事件上自动生成、刷新、按首次或实质变化打开；页面与侧车只写调用者指定目录。
- **非目标**：不做监控、不做第二进度、不写任务状态、不新增页面权威、按已认证最初模板修复卡片视觉和三类目录，不另造导航或改变当前已确认偏好。
- **与其它 Phase 的区别**：P4 管清单/游标/成本；P5 管页面派生与事件；P12 管逐 AC 终末对账。
