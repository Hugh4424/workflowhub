# 代码改动域 · 记录

定位：本组只写「这次跑什么、原件放哪、没跑怎么写」三个动作。读者：实施者、独立测试者、build-code 终末。
边界：测试范围与证据留存的规则正文在 AGENTS「测试硬规则」「证据硬规则」与标准工作方法；本文件全部指向，不复制任何一条。

## 规则

1. 本次跑哪些命令由本 Phase 卡的 `gate_cmd`／测试面决定；范围纪律见 [测试硬规则](../../AGENTS.md#测试硬规则)，此处不重述（强制：审查问句；锚：[测试硬规则](../../AGENTS.md#测试硬规则)）
2. 每份原件只留一次，同字节复用；保存与复用前按 [证据硬规则](../../AGENTS.md#证据硬规则) 判（强制：审查问句；锚：[证据硬规则](../../AGENTS.md#证据硬规则)）
3. 退出码要真实；没跑的面写「哪一面/卡在哪/什么条件下能跑」，不捏 exit 0（强制：审查问句；锚：[step-run-tests](../../workflows/build-code/SKILL.md#step-run-tests)）
4. 失败原地保留，不改写成通过、不重跑到绿（强制：审查问句；锚：[卡住与升级](../../AGENTS.md#卡住与升级)）
5. 记录落在任务材料的 `quality/tests/` 或 `quality/evidence/`，不自建目录、不建第二进度（强制：审查问句；锚：[vNext 永久实施边界](../../AGENTS.md#vnext-永久实施边界)）

## 边界与不承接

范围纪律、证据留存、卡住升级三件事的正文都在别处；本文件与它们重复一句都算第二处正文，审查可直接判失败。
