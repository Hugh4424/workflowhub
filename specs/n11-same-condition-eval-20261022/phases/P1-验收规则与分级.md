## L0 — 结果与变更

本 Phase 只改「怎么验收」：把会逼出全量重跑的规则换成默认最小范围加一次可说明的例外，并要求验收资产开工前齐备、跳过项留痕、新增文件有登记。P2–P9 的验收口径都从这里取，所以它必须最先落地。

- **结果**：任一 Phase 的验收默认只跑本任务范围内与本次改动相关的测试；判断不了影响面时用最小可证伪集合并记录未知影响面；全局重跑只在改动对象是流程本身且局部无法证明时执行一次并事先说明；跳过项记 `unverified` 加原因与影响面并留在分母；四项禁止各有受控负例；本任务新增的实现脚本在 `docs/architecture/move-map.json` 有登记行。
- **非目标**：不放宽任何真实测试范围，不新增分级档位、stage、门或第二进度权威，不新建技能、标准或模板，不替 P2–P9 写它们的测试。
- **与其它 Phase 的区别**：P1 只交规则文本、模板清单与登记行；P2–P9 各自承担其主题的实施与验收，并把本 Phase 的口径作为固定开工输入。
