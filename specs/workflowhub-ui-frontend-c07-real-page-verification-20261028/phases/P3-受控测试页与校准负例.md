# Phase P3 — 交付一套能被判定器读的受控夹具：九类预置缺陷页、缺陷清单、四条校准负例与自洽契约测试

## L0 — 结果与变更

### 这个 Phase 做什么

交一套按名可读的受控夹具。
一个页面装九个可定位的缺陷，每个带固定 id 与 `data-region` 双标记。
一份清单把每条缺陷的 id、选择器、维度、期望档位与检测方法写成机读字段。
四条校准页各带一组基线与观测值；三条还原偏差是重要档，一条主操作被遮罩接管是阻断档。
一份契约测试证明四者互相引用、档位不越界。
这个 Phase 不注入、不运行采集器、不判任何真实页面。

### 交付什么

交四件东西：
- 一个受控页：九个 region，单文件、内联样式与脚本、无外链。
- 一份缺陷清单：九条 region 与四条校准条目（三重要加一阻断），每条五个必填字段。
- 四条校准页：字体 20 到 17px、间距 16 到 8px、颜色 `#1A73E8` 到 `#3A83E8` 三条重要档，加一条阻断档——主按钮命中区被全屏遮罩接管。
  阻断档不靠像素百分比，靠可操作性事实：`document.elementFromPoint` 落在遮罩上，主操作点不动。
- 一份自洽契约测试：字符串与结构断言，不启浏览器。

### 为什么现在做

末验收要拿这套夹具做注入与复测，没有它那一步无从下手。
它只依赖 P1 的档位词，可与采集 Phase 并行。
它不启浏览器，失败面小：七个文件落盘且契约测试成立就算完成。

### T007 — 任务 1：受控页装齐九类预置缺陷，清单按五个字段可机读

受控页装九个 region，每个 region 对应一类已知缺陷。
页面单文件、内联样式与脚本，缺陷是结构性的，不是白屏。
清单把每个 region 的 id、选择器、维度、档位与检测方法写成机读字段。
检测一栏写成「量加判据」，不写「看起来会溢出」。

这张卡要落什么，逐条对照：

| 位置 | 必须出现 | 出处 |
| --- | --- | --- |
| 受控页九个 region | 每个带 id 与 data-region 双标记，顺序固定 | 契约决定 7 |
| 受控页资源 | 单文件、内联样式与脚本、无外链 | 契约决定 7 |
| 清单结构 | regions 与 calibration 两个数组 | 契约决定 7 |
| 每条 region 字段 | id、缺陷 id、选择器、维度、档位、检测方法 | 契约决定 7 |
| 三档词 | `BLOCKER`、`IMPORTANT`、`MINOR` | 契约决定 6 |
| 检测方法 | 量加判据，指向可观察量 | 契约决定 7 |

九个 region 一行一个，维度与档位写在行内：
- `R1-hash-tooltip`（overflow，IMPORTANT）：64 位哈希重复八次放进定宽浮窗，`white-space:nowrap`。
- `R2-long-text`（layout，IMPORTANT）：真实长中文串加不换行，撑破容器。
- `R3-narrow`（layout，BLOCKER）：640 与 320 两个断点下两列负外边距重叠。
- `R4-zoom`（layout，BLOCKER）：固定像素宽容器加绝对定位标签，200% 下遮挡正文。
- `R5-scroll-occlude`（interaction，BLOCKER）：`position:fixed` 底栏盖住可点击按钮。
- `R6-hover-bridge`（interaction，IMPORTANT）：触发区与菜单留 8px 空隙，指针穿过即消失。
- `R7-keyboard-focus`（a11y，BLOCKER）：`tabindex="3/1/2"`，`:focus{outline:none}`。
- `R8-reduced-motion`（interaction，IMPORTANT）：一条动画在 `prefers-reduced-motion` 内，一条在外。
- `R9-error-permission-repeat`（interaction，IMPORTANT）：三点完不出 `data-state` 文案。

步骤：
1. 页面写 `lang="zh-CN"`；九个 region 各用 `id="r<n>-<slug>"` 与 `data-region` 双标记。
2. 逐条写缺陷结构：哈希浮窗、长文本、窄屏、缩放、滚动遮挡、悬停桥、键盘顺序、减动效、错误态。
3. 每条标维度与档位：布局、交互、无障碍；档位取三档之一。
4. 清单固定结构：`schema_version`、`page`、`object`、`regions`、`calibration`。
5. 每条五个字段：`id`、`defect_id`、`selector`、`expected_dimension`、`expected_severity`。
6. 每条的 `detection` 写量加判据：`scrollWidth>clientWidth` 或容器相交。
7. 其余判据用 `elementFromPoint`、计算样式与 `matchMedia`，不写观察句。
8. 不运行浏览器、不注入、不修任何 region。
