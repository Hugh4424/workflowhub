## 实验结论

- 够写出形状：章节骨架、字段位置、场景、环境、谁判、承接都能落位；
  三份片段按自评有省略，不是完整材料。
- 不够稳定写出效果判据：只写出一条能判效果的 `AC-EFFECT-001`。
- `AC-EFFECT-001` 的关键：绿而错变体先过该 Phase 的全部门禁、契约测试、断言与回归，
  再被只读验收与原始需求、不读方案的独立判定者盲判拒绝；真实消费者在真实场景用一次。
- 两处结构冲突：规格验收块只有四标签，没有环境与数据、谁判、承接；
  Phase 的 `gate_cmd`／`Done` 要求一条命令重放，语义判定写不成命令。
  作者拒绝伪造，记 `gate_cmd=unavailable`、`Done=incomplete`。
- 两处局限：作者读过整份写作技能，系统提示还带了仓库规则，不是无背景陌生人；
  没有第二位独立作者重写，也没有独立判定者复判。
- 作者建议：另一位独立作者只拿三份模板、十一条与原始需求重写；
  再由独立判定者按它判一个「绿而错」交付。

## 边界

本目录只保存这一次实验的原件与来源说明，不证明新作者能稳定写出效果判据。
五处模板缺陷的回修在主仓三个模板，不在本目录；本目录不是那次回修的验收证据。
