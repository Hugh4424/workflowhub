Codex 退出、`audit after` 扫净且容器已不再挂载源码后，宿主对**同一 prepared 源码副本**执行 `test <prepared.json> after`：必须只改 `stage-handlers.mjs`，同一冻结测试/helper SHA、同一目标命令、2 pass/56 skipped、exit0，UI QA 与 AC 执行复用同一 ref/hash，受控 adapter 调用恰一次；其余失败、空跑或借 fixture 自称真实浏览器效果均不能算绿色。此 GREEN 是 handler 编排合同，不是 P11 真实页面完成。
