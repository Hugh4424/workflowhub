# 来源登记合成一处权威，并处置不可复算的哈希

## Status

accepted（2026-10-16，make-decision 阶段，任务 `n2-skill-catalog-portability-20261016`）

技能来源登记收敛为**一处机器权威**：机器清单为唯一权威并做完整登记（来源仓、相对路径、稳定章节、采用内容简述、许可、取回坐标）。**技能自带的那份退成便携小卡**——只留最小信息，供技能被单独搬走时随身携带，并由人读流程写清它不是权威。**人读索引不再转述状态、版本、来源**。当前**不可复算的哈希按既有决定处置**：升级到可复算对象，或删除 hash 字样；**不维持现状**。**不新增第四份登记。**

## Considered Options

- **维持两处双写**（机器清单与技能自带 `sources`）：实测两处现在都零生产消费者；当前内容一致，但没有任何一致性检查在对账——这正是本仓历史上出现过漂移的形状，不采。
- **把技能自带那份直接删掉**：字节最省、双写最彻底，但技能被单独搬走时随身没有任何来源信息；用户选择留一张最小便携小卡。
- **新增第四份统一来源登记**：与「不新增第四份登记、不新增字段族」的边界冲突，也是在没有真实消费者时再造一个控制面。
- **普遍给 `adapted` 项补内容哈希**：[ADR-0042](<docs/adr/0042-provenance-hashing-bounded-to-recomputable-vendored-subset.md>) 已否掉这条（手填哈希正是它明文禁止的），本次不重开；只保留「仅对可复算的 vendored 字节算指纹」这一档。
- **让人读索引继续承载来源与状态**：与本轮的瘦身选择相反；实测索引与清单的冲突不止 6 行（另有 7 行同类冲突）。

## 三项判据

1. **难以反转**：真——它一次改掉机器登记、技能自带小卡与人读索引三处的职责，并改变了一处既有方向（见下）；回退要重写三处、重开已经关闭的取舍。
2. **无背景会意外**：真——读者在技能目录里仍会看到来源小卡，也会看到清单与旧索引并存过，会问「到底该信哪一份」；答案在「一处权威＋便携小卡＋人读非权威」这一组里，不在代码里。
3. **存在真实取舍**：真——在「彻底删掉自带来源，最省字节」与「留一张便携小卡，保证单技能搬走时带着来源」之间选了后者；在「普遍补哈希」与「只对可复算的 vendored 字节算指纹」之间维持后者。代价是本轮字节只减不增的目标要靠删重复副本、不靠新增字段来支付。

## Consequences

- **指纹落地依赖后续接线**：`adopted` 与 `content_sha256` 两个字段从未落地（清单与检查器中均 0 次）；本次只建立字段与可复算事实，指纹的机器复算依赖检查器接线（归 N10），**不得声称已生效**。
- **删不可复算的哈希**：`skills/reuse-registry.md` 第 91 行那条全仓唯一、没有可哈希对象的 sha256，按既有决定 [ADR-0042](<docs/adr/0042-provenance-hashing-bounded-to-recomputable-vendored-subset.md>) 处置——升级到可复算对象，或删除 hash 字样，不得维持现状。
- **许可与版本缺口如实保留**：来源包许可链未核实的（如 pstack）如实记缺口，不写「已核实」；无 git 历史的来源包按真实归档指纹与取回坐标登记，不伪装固定版本。清单里那条「用户本地提供的来源」保留为合法的另一种来源类型（保留其授权依据），缺失字段如实记缺口，不伪造成固定提交。
- **手动上游变化步骤写进来源登记的使用说明**（机器清单抬头与维护者看来源登记的地方）：给可照做的步骤，只报告、不自动改；不新增文档、不在每个技能正文重复。
- **方向改变与悬空引用**：[ADR-0042](<docs/adr/0042-provenance-hashing-bounded-to-recomputable-vendored-subset.md>) 正文引用的 `docs/adr/0013` 所指的那份决定（拒绝收敛到单一来源）在当前目录**已不存在**——现 `docs/adr/0013` 是 mini-task 精简功能交付流程，不是被引用的那份。本决定据此显式记录该方向已经改变，并如实保留这处悬空引用为缺口；不改写 ADR-0042 或任何既有文件。
- **编号缺口**：本目录当前最大编号 0044，另有 5 处重复编号（0002、0009、0025、0027、0031）；本次新增取 0045、0046，不重排、不改名任何现存文件，重复号的归属留待其归属处理。
- 来源分层的固定定义（机器清单／人读索引入口／技能正文来源段三层，许可登记为对外出口）落在术语表，供后续 build-plan 与实施消费，不在这里另建一份规格。
