# ADR 0006 — 单一 build-code 合同与可组合职责

- Status: Accepted

`build-code` 保持一个宿主中立的权威 Skill，并在同一合同内提供可组合的“阶段协调”和“Phase 执行”两部分。单执行者按顺序完成两部分；宿主也可把两部分交给不同执行者，但不得改变顺序、证据或权限边界。该决定取代为 Phase 执行另建 Skill、或在宿主提示词中复制开发流程的方案，因为两者都会产生第二份流程合同并造成漂移。

这项决定难以随意反转，因为 Stage/Phase 证据和调用边界依赖同一合同；没有背景时，在不新增 Skill 的前提下支持分工会显得反常；它来自“单一权威”与“宿主可分工”之间的真实取舍。后果是 WorkflowHub 只维护一套开发流程，宿主只映射职责；代价是两个部分必须保持可独立阅读且组合顺序明确。
