# 不以控制成本替代质量：审查不设推理预算与输入量上限

父任务把「给审查限推理预算」与「给送审材料设输入上限」列为候选。本仓**明确不做**这两个候选，也不以任何数量、条数或长度限制去换取效率：材料超限时如实记 `unavailable`，不截断、不因达到异源下限就取消剩余请求。依据是用户 2026-10-16 的原话「不要设置任何数量和限制，只能降低质量，我不希望通过控制成本的方式增加效率」。

这偏离了「先控成本再谈质量」的常见直觉，因此记下：本仓的效率只允许来自**去掉无信息的重复**（例如取消细节审查里同一模型换角色再跑一遍的配对，ADR-0044），不允许来自削材料、削推理或提前中断已发出的审查请求。

## Considered Options

- **后置但写清触发条件**：被用户以同一条原则否决（未采纳）。
- **本次就实现两个上限**：需要先实测投递口径并改审查协议散文，且直接触犯上述原则。
- **明确不做并记录理由**：采纳。

## Consequences

- 审查成本不设本仓上限；成本—发现曲线（父需求 D-015 提到的候选）在本仓不再是待办项，若要重开须由用户新决定。
- 「未知」「不可用」「超限」保持可读且不阻断推进：漏报这些状态比多花成本更严重。
