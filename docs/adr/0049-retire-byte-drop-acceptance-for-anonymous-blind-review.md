# 退役「材料总字节下降」验收口径，改由独立方匿名盲评证明文档质量更高

## Status

accepted（2026-10-16，make-decision 阶段质询后定稿，任务 `n4-writing-templates-research-eval-20261016`）

N4 是写作规则、四类模板、研究来源与评测合同的完整 owner，父需求给它加了一条额外子句：**材料总字节必须下降且下游不回改**。这条子句被**退役**——不再作为验收条件，同一轴上的字节基线（「相对开工基线不增加」）与字节分母口径一并退役。**取代它的是独立方匿名盲评**：改前样本取归档真实材料、改后样本用同题重写，标准在判定前定死，判定由不参与本次改动的一方做；逐维度给「更好／打平／无法判断」，再给总体结论。父编号（R-005、R-012、AC-004、AC-013、ORACLE-T3）**全部保留、不重编号**，退役的只是这些编号下的字节子句；归档记录与父原件一个字不改，不声称已批准删除任何文件。

## Considered Options

- **保留「材料总字节下降」当验收条件**：这是父需求原字面。它把「文档更好」偷换成「字更少」，会诱导为凑数字加限制、删必要内容，反而压低质量，正是用户明确否掉的做法。
- **中间口径「必留部分更短」**：只让必留部分变短、其余不管。它在同一轴上被用户的第二次真实选择覆盖，不作为最终口径，**两个值不得并用**。
- **换一个客观量当替代**（行数、单节占比、句长、篇幅硬线）：本仓 ADR-0037 与 ADR-0043 已否自动可读性评分与字数门；再引入一个数字就是把同一个问题换个名字。
- **完全退役字节口径，改用独立方匿名盲评**：选中。主观判断有噪声，但噪声可以用「标准先定死 + 样本匿名 + 逐维度记三态与原因 + 记录分母与不可判定项」压到可读；字节量则连「更好」都测不到。
- **只退役正文口径、保留字节基线用于核销改动**：等于把退役做成半截——基线不增会重新变成隐性验收条件，故一并退役。

## 三项判据

1. **难以反转**：真——它改的是验收口径本身，并连带取消「字节基线／分母」这一整套核销方式；回退要重新定义「改动大小」怎么被判，并重开已经关闭的取舍。
2. **无背景会意外**：真——父需求原文仍写着「总字节下降」，而本仓此后不再考核任何字节量；读者看到材料变长却仍判通过，会问「为什么」。
3. **存在真实取舍**：真——在「字节下降」这个客观、便宜、但会伤质量的量与「产出文档质量更高更专业」这个主观、昂贵、但指向真实目标的判断之间选了后者；代价是失去一个客观量，并且**必须有人真的看盲评结论**。

## Consequences

- **不再有字节分母可以增删，也不再有「基线不增」可以核销改动**：G1 只剩「声明删除/合并/降档了什么」这一义务；「只加规则而未简化既有物」的判据变弱，由声明与独立盲评共同承接，声明不实由独立方用真实 diff 与读回发现，**记为事实而不作门**。
- **不在任何位置重新引入字节量**：后续 spec、Phases、验收材料若重新出现字节基线、写集分母或「基线不增」核销，按违反本决定记事实。
- **盲评的口径与「无法判断」**：五项质量维度（读者能否独立行动、本类必留项是否在场、引用是否可核、失败与权限边界是否保留、篇幅是否更集中）与三态属**已解决方向**；「无法判断」如实记录原因、不折算成「更好」，某维度在全部样本上都「无法判断」时该维度按未达成记缺口。字段级实现与数值阈值不在这里写。
- **可客观检查项与盲评分列**：机器侧漏检修复、只报告语义、旧材料可读、必留项在场各自独立报告，不用盲评替代；盲评也不用来替代这些可客观项。
- **与既有决定的关系**：本决定不推翻 [ADR-0037](<docs/adr/0037-adopt-cross-language-writing-rules.md>) 与 [ADR-0043](<docs/adr/0043-document-standards-checks-are-report-only.md>)——它们否定的是自动评分器与字数门，本决定同样不引入评分、字数门或阻断行为。
