# 0039 — 证据证明范围改为路径与 hash

原先要求把本 Phase 实际改动文件的**原始字节**连同路径与 hash 一起保存。实测该口径与「每类事实只留一份原始件」相乘后无法收敛：同一命令重跑、同一 provider 输出逐份写盘、目录族重复采集都没有任何短路，产物规模以数量级增长，而"重复存证"在系统里没有消费者。决定改为：**同一事实＝字节相同**；重跑得到逐字节相同的结果时，复用既有原件、只写引用而不新写；证明范围改为**只写路径 + hash**，字节留在工作树。

## 否掉了什么

不新增去重校验器或检查工具；不设数量阈值或篇幅指标；不在本轮清理历史产物（历史清账需另开明确授权、逐件复核）。例外仅三类仍附字节：该文件随后会被改动或删除、外部服务返回体、一次性环境读数。

## 后果与风险

工作树被改动或清理后，仅凭路径与 hash 无法再核内容。因此复用判据必须保守：只有在命令逐字相同、既有 ref 存在且能确立内容相等时才复用；**无法确立内容相等时保留新件并记 `deduplication: unknown`**，不得据字节数判定为重复。真实失败、取消、超时与迟到发现永不因复用被抹掉，且任何被 ref 指向的件一律按唯一原件保留。

## 三项判据

- **难以反转**：真 —— 字节不再随证据保存；工作树被改动或清理后，仅凭路径与 hash 无法再核内容，事后无法补回。
- **无背景会意外**：真 —— 后来者会问「为什么证据区里没有原始字节、却声称证明了改动范围」。
- **存在真实取舍**：真 —— 用可核性换取收敛；替代方案（加去重校验器、把 quality/ 纳入 ArtifactDir、设重复率指标、清账加唯一原件索引）已逐条评估并拒绝。
