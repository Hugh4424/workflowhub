# Reuse registry

复用来源、固定版本、许可和上游地址以 [`skills/catalog.yaml`](../skills/catalog.yaml) 及各技能 `SKILL.md` 为准；本文只解释复用职责，不成为 registry、推进许可或第二个质量裁决者。

## 状态词表

复用状态保留 `native`、`adopted`、`adapted`、`absorbed`、`rejected`、`watch`。已采用技能保留原来源与许可；不因本卡去 hash／认证机制而删除真实授权或上游版本字段。

## 当前消费者

post 的 make-decision、build-plan、build-code、verify-code 使用现五阶段技能正文、当前材料及任务事实；pre/history 的旧四材料和原审查、测试、receipt 保持只读。自定义技能的真实指标按现 producer／consumer 留普通事实，不以 catalog 标签代替真实执行。

`wh-review` 保留文档 executor 与当前 `ReviewProviderClient` 运输职责；代码使用 OCR。真正工具缺装才允许原 fallback。未证明安全运输的 provider 真实 unavailable；缺独立数量不削减 quorum，有效单源发现及 raw/provenance 保留。文档和代码审查不能互相冒充执行。

原 M14–M17 的八消费者 journal／receipt／audit aggregator 和重试绑定描述已退役，历史决策以 Git 及已声明只读档案查阅；不恢复第二套 verdict authority、会话许可或未来 actor。`debate` 等现已采用的可选诊断仍按 catalog 记录，不进入核心 Bundle 或普通推进前置。
