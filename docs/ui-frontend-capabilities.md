# UI 与前端能力清单

本表是 workflowhub 唯一一张 UI 与前端能力台账：查任一能力归哪个阶段、何时触发、产出什么、怎么验、现在什么状态。
消费者是第 2–9 段作者、项目维护者与独立读者；其他材料引用本表，不另存第二份。
覆盖上限：本表只证能力有阶段与验法可查，不证阶段真的调用了能力；状态列是初值，不是对账结论。

## 能力台账

本任务承接指本任务对这项能力做什么；原卡验收归属指原卡验收由谁判，本任务是否重验。

## 维护者与更新时机

- 维护者：阶段方法负责人，即以后改这些阶段方法的人。
- 更新时机：能力变更时、所引阶段方法变更时、任务收口对账时同步本表。
- 状态格格式约定：以「已接线」「部分」「未接线」「仓外」之一开头，可紧跟一个括号括注，如「部分（缺第 3 段）」；括注不是第五个档位，不改变档位，词表仍是四个。第 9 段对账照此写。
- 只放一处：本表是唯一 UI 能力台账，其他材料引用它，不再另存一份。

## 边界与不做什么

- 不新增能力，不重建退役阶段，不改写 PRD 历史正文。
- 不把“技能文件存在”当成“已接线”；状态要有仓内读取处或产物路径为证。
- 本表不作第二进度权威，也不作阶段继续工作的许可。
