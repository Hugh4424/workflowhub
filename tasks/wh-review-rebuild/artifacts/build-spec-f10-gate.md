## Q3：能否被绕过（安全剧场风险）？

| 机制 | 可绕过路径 | 评估 |
|---|---|---|
| wh-review 合同路由 | stage agent 可直接调用 3rd-review 绕过 wh-review | 风险：低。spec 要求 stage agent 调用 wh-review，架构约定；绕过行为在日志中可发现 |
| D2 人工确认门 | 实现者可省略挂起逻辑 | 风险：中。AC-D5 提供机器可查验收条件（pass 分支无自动推进逻辑），verify-code 阶段可捕获 |
| 收尾统一模板 | 实现者可保留旧收尾逻辑 | 风险：低。AC-D6 要求逐一核实，不符即失败 |

**结论 Q3**：D2 人工确认门存在被实现者省略的风险，已在 AC-D5 中设置机器可查的验收条件，不构成安全剧场。其余机制不易绕过且验收条件明确。
