## 反例与核对

视觉核对要区分角色正确、映射已核和页面已验三件事。

错误写法：“未知状态使用健康角色，因为两者当前颜色一样。”错误原因：值相同不能证明语义相同，外观会掩盖未知事实。

核对动作：设计owner逐角色对照原用途；CSS/token owner核实际绑定。若页面验证尚未执行，独立验证者将对比度、主题、可读性等观察保留未验证，并引用质量源的适用判据。角色表存在不证明视觉通过。
