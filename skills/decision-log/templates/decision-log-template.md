# 决策日志（decision-log）

读者：make-decision 主会话、build-plan 与 build-code 作者，以及回读验收和风险的 build-code 终末 作者。
读完要能：定位真实需求、已确认决定、写入范围、验收索引与原件；区分示例、实际事实和缺口。

引用外部来源时写清版本与回原文的直达链接；版本/签名类事实须实读依赖文件并写出处，取不到写 `unverified` 与具体缺口。推断就地紧跟“这是推断”及依据，不分小节、不加新符号约定；不要求所有断言都外部引用。

本模板只安排正文，不认证身份或授权。以下示例演示写法，实际日志以本任务真实来源替换；这是写作指引，不是质量门。

本类 P0 必留内容如下。该声明属于当前模板的人读选节指引，不是全仓固定清单，也不新增 runtime 标题、字段或质量门。

| 必留内容（P0） | 本模板已有落点 |
| --- | --- |
| 任务身份和原始需求 | 任务身份；原始需求 |
| 最小大纲与整体故事 | 大纲地图；范围与非目标 |
| 当前决定及理由 | 工作包与决定 |
| 范围/非目标 | 范围与非目标；要改哪些文件 |

生成时逐项在上述既有落点标状态，声明与实际内容一致才算在场：`written` 指向已写的必要内容；`not-applicable` 必须写不适用理由和依据，不能用它掩盖缺失设计；`deferred` 必须写责任卡、触发条件、受影响结果。P0 标题保留，deferred 只声明缺口和承接，不删除必要标题，也不冒已完成。P0/P1/P2 决定是否选节，三态决定在场内容的状态，两者不互相代替。

四级路线均保留骨架、收敛与整体故事；单模块可用一项骨架和一段故事。P1 由真实多模块关系、取舍、变更、未决或退役触发：按实际对象展开关系、替代方案或相应节；没有事项时说明无及依据，不留空壳。P2 仅在具名读者需回读过程时引用既有原件，已关闭过程不复制进当前决定。

## 级别与路线

本节是流程、实施/审查、收口与验收的唯一入口事实读点；由当前 make-decision 主会话单一 writer 依据真实调用与用户答复写入。模板尚未执行调用或取得答复，不提供示例取值冒事实。

只在本节写入 status、reason、expanded_risks、choices 与七项输入判级事实及逐项来源，承诺的独立可交付验收单元数、是否含需要用户在场或真实凭证的动作及逐项来源，实际调用命令、返回原 ref 的唯一可回读指向。推荐级别、理由、真实用户选择与覆盖旧/新级别、来源和影响沿当前入口方法写入本节，历史追加保留；原始返回单份沿唯一原 ref 保存，工作包决定只引用本节稳定锚和必要决定含义。

返回未包含项写“未返回”，不补造值；缺来源写 unassessed 与具名 owner，函数不可用、材料不足或取值缺依据记未评估/未决。paused 时在第8步与第13步同批展示至少一条可选拆分路线，不把建议当许可。原 ref 缺失或不可回读时报告原件不可得、具体缺口与 owner，按复杂处理，不以其它节原值兜底，不另存或复制 raw；未答不当用户授权，其余安全工作继续。

#### ADR-001 — 让下游直接取得已确认方向

- **做什么**：主文保留下游要用的方向与接口。
  - 每条原始需求保原义、来源与落点；真实来源未提供时写缺口。
  - 依据引用本任务真实选择原件；此示例尚无实际确认。
- **不做什么**：历史过程只引用唯一原件，不复制成第二正文。
  - 过程不复制，避免双份维护。
- **风险**：原件缺失时相应依据保持 unknown，由来源 owner 补路径。
  - 方向冲突交主会话与用户处理；缺口不能当作已确认。
- **改动**：本例仅演示模板形状，实际任务填写受影响的文件与符号（不含行号）、行为变化和唯一 writer；取值与字段级方案由 `spec.md` 的实现设计承载，数值唯一来源为生产代码内的既有具名常量，此处不写判定阈值数值或可粘贴代码。

#### D-0xx — 在现有确认里展示入口评估事实

- **做什么**：只引用本日志[级别与路线](#级别与路线)及该节真实原 ref，保必要决定含义；本例尚未调用或取得真实答复，不提供取值。
- **不做什么**：不复制返回取值、输入或代价事实，不据此自动改任务性质/路线，不设通过阈值，不阻断无关安全工作，不要求提前提供真实凭证。
- **风险**：原 ref 缺失或不可回读及来源缺失均沿唯一节保具体缺口与具名 owner，不用本决定的重复原值兜底，不补造成功。
- **改动**：make-decision 主会话为唯一 writer；第8步粗粒度确认与第13步方向确认读者引用同一节及唯一原件，展示真实事实/建议，用户实际答复或未答沿原记录保留。

失败恢复：指针缺失由当前作者补真实来源；方向冲突交主会话与用户。旧决定保编号/原件指针，再引新决定。

每个决定固定四个父字段：做什么／不做什么／风险／改动。做什么写选定结果、前提和动作，并就近保关键来源、约束与拒绝替代理由；不做什么写会误扩范围或拦住执行者的真实边界；风险写本决定独有的触发、后果、缓解／恢复及未解 owner；改动写精确文件路径与符号名（不含行号）、行为变化和唯一写主。

父字段先写一句字段级结论；多件事用子要点，每点（含子点）只讲一件事，首句为结论，依据与例外跟后。标题含动作动词，脱离正文可读目标；要点数量不限，不要求每块恰好或最多四条，不设长度、字数或评分控制面。

完成判据：每包有结果、消费者、来源、四字段决定、具名失败恢复路径及可回读的实际确认；当前决定正文单写，其它处引编号/条件指针。现 N／ADR／D 编号、五字段历史原件不变。
