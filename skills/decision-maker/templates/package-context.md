# 上下文包（模板）

一个包一份，一页加引用。
只给任务库路径，不给整段会话；缺哪项写缺口和谁补。

## 包

- 包号与名字：`<...>`
- 目标（一句）：`<这个包最后要让谁看到什么>`
- 需求原文与来源：`<原话或原义；ref 与位置>`
- 现状证据（现在为什么做不到）：`<事实；ref>`
- 调研来源与已得结论：`<结论；ref>`
- 前序决定（只引编号和指针）：`<决定编号；ref>`
- 边界与非目标：`<做什么、不做什么>`
- 验收三件套：命令或检查 `<...>`；反例 `<...>`；证据路径 `<...>`
- 开放问题（谁定）：`<问题；owner；时点>`
- 输出路径（本包材料放哪）：`<ref>`
- 卡模板：`card.md`

## 缺项

- 缺什么：`<...>`；影响哪一步：`<...>`；谁补：`<owner>`。
