# 作者开工契约

本契约让下一位读者找到第一步、判定与失败恢复。
适用对象是 build-plan 的 Phase 与测试设计作者；派发 brief 必须附本件路径。
材料形状按 `skills/material-writing/SKILL.md` 的「材料写作标准（唯一）」执行。
十九条自查见 `skills/spec-specify/SKILL.md` 的 Q13；开工时逐条读取并核本次适用与例外。
本件只写开工动作与失败恢复，不复制第二份标准。

## 五问

开工前写下五问答案，答案进入当前 brief 或本次唯一执行原件。

1. 为谁做：点明下一位读者，而非只说“代理”。
2. 他拿它干什么：写读者的实际动作与结果。
3. 读到哪里会卡：写缺的输入、术语或首改位置。
4. 失败怎么恢复：给失败信号、原 owner 和恢复条件。
5. 哪些话只有内行懂：解释首现词，精确代码名留原样。

## 禁止模式

写作要求与行宽按 `skills/material-writing/SKILL.md` 的「材料写作标准（唯一）」执行。
本件不复述。
精确命令、引用与锁定合同保原字节，并逐处注明例外；结构读数不替代语义判断。

只有字段没有卡内正文、同一含义多处定义、无来源编号堆叠，都会让读者缺少开工依据。
把所有恢复写成“重试”会掩盖原失败；应写哪个信号出现后交谁修什么。
空表、占位与固定常量不替代真实输入；适用内容逐项填写，未取得给 owner 和恢复条件。
证据计划、预写测试、可观察接缝与测试变更请求的义务归原 Task 字段，不因删标签消失。
历史 G-2 的 RED 证据声明仍按 Phase 模板的具名边界填写。

失败怎么办：独立读者找不到第一步或坏输入被当成功时，回原作者修材料与检查；保原答、原错误及冻结 oracle。

## 发布草稿

公开草稿入口允许先写骨架，再补完整规格与索引。
build-plan 可先保存具名 Phase，再生成纯指针 index；make-decision 的 Phase 仍须在索引内。
独立 Phase 中已定义的 Task 卡须有字段之外的实际正文；卡外叙述、注释、引用与围栏示例不能代填。
这条底线复用 `runtime/stage/stage-content-contracts.mjs` 的同一正文判断。
保存时不要求其它材料、追踪或全部机器字段已齐；完整计划仍沿原完整合同检查。
写入失败时保原错误与目标原件，回原作者修同一卡，再重放同一公开调用。
写入成功只证明这次保存，不证明读者理解或计划合格。

## 完整作者消费

验证作者方法或模板效果时，实际执行 `skills/spec-plan/SKILL.md` 的「Test design and quality」完整作者消费。
调用者提供具源真实新 Task、实际代码接口与本次要求的材料范围，不给现成设计答案。
未参与实现的作者用空继承上下文（none）启动，依当前通用方法创作；保存每份唯一原件及逻辑路径映射。
决策日志、全局规格、独立 Phase 与纯指针索引按该真实任务填写，依赖源于实际交付。
另一独立读者对原需求、写集、前置与失败恢复逐项定位，并执行真正相关、无生产副作用的命令。
保作者身份、实际产物、独立对照和命令原件；未齐只报缺口，不称效果已经成立。
原输入本来通过就保真实基线；模板在场、替换示例路径或身份命令只证对应有限事实。

## 好例与坏例

下面两段展示同一失败恢复含义，样例不冒执行事实。

<!-- contract-example:good -->
操作者需要定位配置错误。
读取指定文件，校验后返回带路径的错误。
文件不可读时保原错误，交配置作者修复路径。
输入恢复可读后，重放同一检查命令。

<!-- contract-example:bad -->
对多维能力进行实施，大家都懂，失败则按既定流程处理。

坏例至少暴露两处缺口：名词化动作没有首改对象，内行话没有解释；失败段也缺 owner 与恢复条件。
好坏判断的上限是这些可观察差异，真正可用性由未参与写作的独立读者消费实际完整材料判定。

## 怎样调用现有辅助检查？

计划作者沿build-plan已有本契约指针读取，再按当前真实材料调用；bundle只分发这些文件，不执行脚本。

- 决策基线：`node skills/spec-plan/scripts/build-decision-baseline.mjs --decision-log <当前decision-log.md> --spec <当前spec.md>`，stdout为基线JSON；0为本次解析，1为输入/结构错误，不证明原始需求已正确理解。
- 读者记录：`node skills/spec-plan/scripts/check-reader-record.mjs <独立读者本次记录.md>`；0仅结构齐，2为具名缺项，1为输入错误；五问答案仍由独立读者负责。
- 作者读数：`node skills/spec-plan/scripts/check-authoring-budget.mjs <当前材料.md>`；正常读取退出0，只输出字数/句长等观察，不作可读性裁决或新门；读不到保非零原错误。

命令经当前任务capture保存真实cwd/argv/exit/原输出，未知来源与未执行面不以脚本在bundle内冒通过。
