# plan-ceo-review

Source: adapted from the project review baseline. Mode: `lens-only`.

## Check

1. State the user problem and evidence separately from derived assumptions.
2. Challenge the narrowest viable scope and identify existing leverage.
3. Compare the proposed direction with at least one credible alternative.
4. Identify a premise whose failure would invalidate the direction.
5. State timing, impact radius, and an explicit recommendation.

## Result

Return observations with concrete packet evidence. This lens only evaluates supplied material.
