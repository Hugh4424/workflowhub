## 背景与目标

CLI 使用者会被默认值掩盖非法配置的位置；本示例的根因结论、目标状态与缺口如下。

- **根因结论**：读取入口把非法配置回退成默认值，使用者看不见位置；来源：旧件 CARD-001:41–48。
- **目标状态**：非法配置显示文件位置并以退出码 2 结束；合法配置仍按既有路径读取。
- **用户故事**：作为 CLI 使用者，希望配置非法时看到文件位置，以便自己修正，而不是被默认值带过；承接 CARD-001。
- **范围**：只含 CLI 读取与错误呈现；配置格式、热更新与认证不在本期。
- **非目标**：不增加配置格式、热更新、认证机制或持久化对象。
- **规划对象设计适用性**：N/A — 本例只含 CLI 输出，无 UI 界面。
- **当前状态与缺口**：draft；示例未确认。真实来源、入口核实与用户答复仍缺，保持 draft。
