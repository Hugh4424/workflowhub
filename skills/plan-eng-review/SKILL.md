# plan-eng-review

Source: adapted from the project engineering review baseline. Mode: `lens-only`.

## Check

1. Map requirements to discrete tasks and objective verification.
2. Validate dependency order, ownership boundaries, and interface changes.
3. Identify failure modes, rollback assumptions, and state transitions.
4. Check task granularity and parallelism claims against dependencies.
5. Check test evidence covers changed behavior and negative cases.

## Result

Return plan anchors, risk, and the smallest corrective action.
