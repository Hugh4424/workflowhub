# 根因影响验收清单

读者：写根因假设、影响面与问题消失验收的人。
读完要能写一条主因加一条排除解释，并把影响面四格填实。

本件只承载「根因假设／影响面／问题消失验收」三段的清单；判据形状指回
决策日志模板第 2 段、决策卡的对应格与 `skills/spec-specify/SKILL.md` 的验收标准节，
不在此复制判据正文。

## 根因

一条主因要能解释所有症状；再写一条排除解释，说明为什么不是另一个更显眼的可能。
读数为证：贴出对照读数，主因成立时读数怎么变，被排除项为何不变。

## 影响面四格

- 调用方：哪些代码或角色会受影响。
- 数据兼容：旧数据与既有格式还能不能用。
- 回滚半径：出问题要回退到哪、影响多大。
- 影响量级：多少人、多少请求或多少条记录受波及。

## 验收与反证

问题消失验收写通过条件、失败条件、至少一个反例与证据路径，四件都要有真内容。
反证登记位：每条主因旁留一格，写「若这条被推翻，看什么读数」，把反证与结论同格保存。
