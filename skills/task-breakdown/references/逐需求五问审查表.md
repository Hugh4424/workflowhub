# 逐需求五问审查表

读者：逐条需求过五问、决定合并、拆开还是加依赖的人。
读完要能用一张表把每条需求过五问，并给出切包排序。

本件只承载「逐需求五问」一段。这里的五问是拆包专用的一套，
不与其它技能已有的五问共用名字而不加限定。

## 五问的问句与判法

- 问题：这条需求陈述清不清？判法：八格齐、来源可回指。
- 存在：最小复现做不做得出来？判法：三态结论。
- 根因：一条主因加一条排除解释在不在？判法：读数对照。
- 影响：影响面四格填没填实？判法：调用方、数据、回滚、量级都在。
- 消失：问题消失验收四件齐不齐？判法：通过、失败、反例、证据。

## 合并、拆分与依赖

- 合并：两条需求共享同一主因同一影响面，且合并后一个包能一次验收。
- 拆分：一条需求里有两个互不依赖的主因，或影响面落在不同调用方。
- 依赖：一条需求的验收要等另一条先落地，就写成前置依赖，不硬塞同包。

## 表形

一条需求一行，五问结论与反证写在同一格，供切包排序。
